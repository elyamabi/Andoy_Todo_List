# Andoy To-Do List — DCIT 26 Laboratory 2

React + Tailwind CSS To-Do List for DCIT 26.

Features: Add tasks, Done/Not Done, Delete, Clear All/reset, React useState/event handling, React components, responsive Tailwind CSS, and User Guide.

Run locally:
`npm install`
`npm run dev`

Build:
`npm run build`

Deploy using Vercel, Netlify, or GitHub Pages as required by the laboratory instructions.
